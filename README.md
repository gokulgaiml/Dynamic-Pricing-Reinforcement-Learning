# Dynamic Pricing using Reinforcement Learning

A Reinforcement Learning project focused on building the data preprocessing and feature engineering pipeline for a Dynamic Pricing System using hotel booking data.

---

# Overview

This project aims to develop a Dynamic Pricing System using Reinforcement Learning. During the first two weeks, the focus was on preparing a clean and structured dataset that will later be used for training a Reinforcement Learning agent.

---

# Project Objectives

- Build the project structure
- Load the hotel booking dataset
- Clean and preprocess the dataset
- Perform Exploratory Data Analysis (EDA)
- Generate pricing-related features
- Prepare the dataset for Reinforcement Learning
- Maintain a modular Python codebase
- Track development using Git and GitHub

---

# Dataset

The project uses the **Hotel Booking Demand Dataset**.

The dataset contains booking information such as:

- Hotel Type
- Lead Time
- Arrival Date
- Number of Adults
- Number of Children
- Stay Duration
- Market Segment
- Customer Type
- ADR (Average Daily Rate)
- Reservation Status
- Booking Changes
- Special Requests
